蓝粉渐变不是越多越好

AAster2026/11/011286

蓝粉渐变很容易让页面“一眼惊艳”，也很容易在第三屏之后变得疲劳。真正难的是克制：让渐变只出现在需要被注意的地方，其余部分交给留白和层次。

先定三个底色

背景、卡片和文字是页面的骨架。先把这三层的明度关系定下来，再决定渐变从哪里开始。

  • 背景：接近白的冷色，带一点蓝。
  • 卡片：半透明白，靠模糊和细描边拉开层次。
  • 文字：低饱和的深蓝灰，避免纯黑。
渐变是强调色，不是背景色。一个页面里，真正需要渐变的地方通常不超过三处。

玻璃层的关键参数

透明度、模糊半径和描边要一起调。透明度太低会显得脏，太高又失去玻璃感。建议从 rgba(255,255,255,.55) 与 blur(18px) 开始，再根据背景复杂度微调。

.glass {
  background: rgba(255, 255, 255, 0.55);
  border: 1px solid rgba(255, 255, 255, 0.72);
  backdrop-filter: blur(18px) saturate(130%);
  border-radius: 22px;
}

把动效留给交互

入场动画只做一次，悬停与点击才是持续反馈。卡片轻微倾斜、按钮流光、滚动进度条，都比整页漂浮更耐用。

最后，记得在 prefers-reduced-motion 下关闭非必要动画。
